# system-design-component

대규모 시스템 설계에서 쓰는 부품을 카드로 정리한 개인 학습 노트.

부품 하나를 다섯 칸으로 적는다.

| 칸 | 내용 |
|---|---|
| when | 어떤 증상이 보이면 이 부품을 꺼내나 |
| plus | 뭘 얻나 |
| **minus** | **뭘 내주나.** "무엇을 못 하게 되나 / 무엇을 새로 관리해야 하나"로 적는다 |
| 기타 | 이 부품을 넣으면 반드시 따라오는 질문과 한 줄 답 |
| usecase | 실제로 어디에 이렇게 쓰이나 |

plus는 검색하면 나온다. minus는 잘 안 나와서 직접 적어둔다.

## 지금 있는 카드

로드밸런서 · DB 읽기 사본 · 캐시 · CDN · 무상태 웹 계층 · 메시지 큐 · 샤딩 · 여러 지역 배치

```

icons/                  아이콘 (icon.svg가 원본)
```
